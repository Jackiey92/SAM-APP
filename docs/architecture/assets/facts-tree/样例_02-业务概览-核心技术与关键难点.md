# 02-业务概览 · 核心技术与关键难点

## 概览
- **一句话定位**：公司核心技术集中在新能源、泛半导体、精密制膜三类装备的精密涂布、流延成型与层压环节，技术主要以专利形态沉淀。[^1]
- **关键结论**：
  - 截至 2025-01 拥有发明专利 5 项、实用新型 53 项、软件著作权 9 个，覆盖流延机、涂布模头、风嘴、自动压合等关键部件。[^2][^3]
  - 近三年研发费用 601.20 / 863.19 / 626.49 万元，占营收比 5.7% / 5.72% / 5.49%，投入稳定。[^4]
- **最新数据时点**：2025-01
- **来源文件数**：1
- **最近更新**：2026-10-13

## 正文
公司围绕"涂布—烘干—层压"整线装备布局技术，专利覆盖流延机、涂布模头、间隙型风嘴、自动堆叠压合等核心部件，其中发明专利「片式多层陶瓷电容器的制备工艺」申请号 2022114729435。[^3]

三类装备均采用"销售 + 定制化 + 技术服务"模式，技术服务与装备交付绑定。[^5]

研发投入近三年相对稳定：2022 年 601.20 万元、2023 年 863.19 万元、2024 年 626.49 万元，占营收比 5.7%、5.72%、5.49%。[^4]（研发费用明细归 L-bizov-11 研发投入；研发人员规模与占比归 L-hr-04 员工结构，本叶不重复存。）
